# Update screenshots

The README images are generated by `scripts/screenshots.sh` from synthetic sources. Never hand-edit the PNGs or capture the user's real desktop.

| Image | Produced from |
|---|---|
| `before.png` | `source/dashboard.html`, rendered by headless Chromium (1200×760) |
| `hero.png` | `before.png` + `source/annotations.json` via `omashot render` |
| `backgrounds.png` | `omashot backgrounds` thumbnails, arranged in a 10×2 grid |
| `editor.png` | `source/EditorShot.qml`, offscreen Qt, applies the annotations and background from `annotations.json` |
| `launcher.png` | `source/LauncherShot.qml`, briefly opens a real window on Wayland (layer-shell can't load offscreen) |

## Steps

1. Run `./scripts/screenshots.sh`. It needs a Wayland session, `chromium`, `magick`, `qs` and `cargo`, and takes under a minute. A launcher window flashes for about a second; warn the user before running if they might be screen sharing.
2. **Look at every changed image** with the Read tool. The script exits 0 even if an image is visually wrong. Check that:
   - toolbar and footer icons are visible in `editor.png` and `launcher.png` (blank icons mean `Icon.qml` doesn't render under the software/offscreen renderer)
   - the launcher background is the dark window color, not white or transparent (the script pins the Tokyo Night theme; `OMASHOT_SCREENSHOT_THEME` overrides it)
   - annotations land where intended in `hero.png` and nothing overlaps awkwardly
   - nothing personal appears (only the Northstar demo data)
3. `git status docs/screenshots` lists what changed. The script strips metadata, so an unchanged UI produces no diff. If nothing changed after a visual change, the change probably isn't covered by these shots.
4. Commit the images together with the UI change that caused them.

## Uncommitted work by others

The script renders the **working tree**. If other uncommitted changes are present that aren't part of your task, render from a clean checkout instead so they don't leak into the images:

```bash
wt=$(mktemp -d) && git worktree add --detach "$wt" HEAD
cp scripts/screenshots.sh "$wt/scripts/" && cp docs/screenshots/source/* "$wt/docs/screenshots/source/"   # only if changed locally
CARGO_TARGET_DIR="$PWD/target" "$wt/scripts/screenshots.sh"
cp "$wt"/docs/screenshots/*.png docs/screenshots/ && git worktree remove --force "$wt"
```

## Changing the demo content

- Dashboard layout/text: edit `docs/screenshots/source/dashboard.html`. Keep it 1200×760 and use only invented names and data.
- Annotations and background: edit `docs/screenshots/source/annotations.json`. Coordinates are in dashboard pixels; the op format matches `omashot render` (see the `render` handler in `src/main.rs`). The editor shot reuses this file, so both images stay consistent.
- Editor or launcher framing: adjust the window size, timing or state setup in `EditorShot.qml` / `LauncherShot.qml`. Harnesses print `SHOT_SAVED` on success; the script fails and prints the Quickshell log otherwise.
- If you add a new image, add it to the `for name in ...` loop at the end of `scripts/screenshots.sh` and reference it from `README.md`.
